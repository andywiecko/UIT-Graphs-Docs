    Plot with filled curves

    Data

    To plot the filled area between two curves, one can use PlotWithFilledCurves. In contrast to, for example, PlotWithLines, the provided data must implement IReadOnlyList<float3>. The y and z components of each float3 element correspond to the first and second data sets, respectively.

    var graph = new Graph { ... };

var data = new float3[]
{
    new(0, 1, 1),
    new(1, 2, -1),
    new(2, 1.5f, -1.5f),
    new(3, -1, -2),
    new(4, 0, 2),
};

var plot = graph.PlotWithFilledCurves(data);

    NaN values

    Similarly, one can use float.NaN to separate input data, as shown in the following example:

    var graph = new Graph { ... };

var data = new float3[]
{
    new(0, 0, 1),
    new(1, 0.5f, 1.5f),
    float.NaN,
    new(2, 0.5f, 1.5f),
    new(4, 0, -1),
};

var plot = graph.PlotWithFilledCurves(data);


    Styling

    This plot type has the same properties as PlotWithLines, with the addition of the FillColor property (--graph-fill-color).



    • USS
    • C# 
    .my-plot {
    --graph-line-color: blue;
    --graph-line-width: 3;
    --graph-line-dash-pattern: "4 4";
    --graph-fill-color: rgba(1.0, 0, 0, 0.5);
}

    var graph = new Graph
{
    XAxis = { Min = -2 * math.PI, Max = 2 * math.PI },
    YAxis = { Min = -0.5f, Max = +.5f }
};

var data = SequencePair.Uniform(x => math.float2(
    +0.1f * math.cos(x) + 0.15f,
    -0.1f * math.cos(x) - 0.15f),
    samples: 200
);

var plot = graph.PlotWithFilledCurves(data, theme: new()
{
    LineColor = Color.blue,
    LineDashPattern = new float[] { 4, 4 },
    LineWidth = 3,
    FillColor = new Color(1, 0, 0, 0.5f),
});
