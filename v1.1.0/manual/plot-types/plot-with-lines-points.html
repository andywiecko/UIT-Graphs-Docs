    Plot with lines points

    Data

    This plot type is a combination of PlotWithLines and PlotWithPoints. See the Plot types/Plot with lines and Plot types/Plot with points sections for more details.

    var graph = new Graph { ... };
var data = new float2[] { ... };
graph.PlotWithLinesPoints(data);

    Styling

    It shares the same styling properties as PlotWithLines and PlotWithPoints.

    var graph = new Graph { ... };

var data = new float2[]
{
    new(0, 0),
    new(2, 1),
    new(2, 3),
    new(4, 2),
    float.NaN,
    new(5, 5),
    new(6, 1),
    new(7, 3),
};

graph.PlotWithLinesPoints(data, theme: new()
{
    LineColor = Color.blue,
    LineDashPattern = new[] {7f, 2, 4, 2},
    LineWidth = 4,

    PointColor = Color.red,
    PointFillColor = Utils.ColorWithAlpha(Color.green, 0.5f),
    PointDashPattern = new[] { 4f, 1 },
    PointSize = 15,
    PointStyle = (int)PointStyle.TriangleUpFilled,
    PointWidth = 4
});
