    Method Clip

    Clip(ref float2, ref float2, AABB)

    Cohen-Sutherland line clipping algorithm. Modifies p and q so that the line segment fits within the specified box.

    Declaration
    public static bool Clip(ref float2 p, ref float2 q, AABB box)
    Parameters
    Type Name Description
    float2 p

    The first endpoint of the line segment.
    float2 q

    The second endpoint of the line segment.
    AABB box

    The clipping bounding box.
    Returns
    Type Description
    bool

    true if the clipped segment lies within the box, otherwise false (no box intersection or invalid values).

    Parameters
    Type Name Description
    List<float2> polygon

    The polygon points to clip.
    AABB box

    The box used for polygon clipping.
    List<float2> tmp

    Optional temporary buffer. Provide list to reduce GC alloc.
    Remarks

    Clipping procedure may produce additionall points. The final clipped polygon can be found in the polygon.
