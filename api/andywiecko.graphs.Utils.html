    CalculateAABB(IReadOnlyList<float2>, float?, float?, float?, float?)

    Calculates an AABB from the provided series of points. The result is optionally constrained by xmin, xmax, ymin, and ymax.
    Clip(ref float2, ref float2, AABB)

    Cohen-Sutherland line clipping algorithm. Modifies p and q so that the line segment fits within the specified box.
    ColorWithAlpha(Color, float)

    Returns the specified color with a modified alpha value.
    DrawLines(IReadOnlyList<float2>, Painter2D, AABB, float3x3?)

    Draws a line series using painter within the specified box. Optionally applies an affineTransfrom to the series before rendering. NaN values can be used within series to split line segments.
    ParseDashPattern(string)

    Converts a string-based dash pattern into an array of floats, e.g. "4 4 2 2" becomes new[] { 4f, 4f, 2f, 2f }. See the tutorial for more details.
    RotateLabel(Label, float)

    Applies rotation to the label by the specified angle. rotate does not support VisualElement bounding box recalculation.
