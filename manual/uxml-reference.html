    UXML reference

    Graph

    Below you can find a schematic overview of the graph UXML structure with the corresponding attached classes. For more details, you can inspect the graph using the UI Toolkit Debugger.

    #Graph .graph
├── #LeftPanel .graph-left-panel
│   ├── #Header .graph-panel-filler
│   ├── #Body
│   │   ├── #KeyLeftSlot
│   │   └── #YLabel .graph-ylabel
│   └── #Footer .graph-panel-filler
├── #MiddlePanel .graph-middle-panel
│   ├── #TopPanel
│   │   ├── #KeyTopSlot
│   │   └── #Title .graph-title
│   ├── #Canvas .graph-canvas
│   │   ├── #XTics .graph-xtics
│   │   │   └── ...
│   │   ├── #YTics .graph-ytics
│   │   │   └── ...
│   │   ├── #Grid .graph-grid
│   │   ├── #Plots .graph-plots
│   │   │   └── ...
│   │   ├── #Border .graph-border
│   │   └── #KeyInSlot
│   ├── #BottomPanel
│   │   ├── #XLabel .graph-xlabel
│   │   └── #KeyBottomSlot
└── #RightPanel .graph-right-panel
    ├── #Header .graph-panel-filler
    ├── #Body
    │   └── #KeyRightSlot
    └── #Footer .graph-panel-filler
    Note

    The key can be found, depending on the selected settings, in different key slot elements (#KeyInSlot, #KeyLeftSlot, #KeyRightSlot, #KeyTopSlot, #KeyBottomSlot). See also the schematic tree for the key below.

    Key

    Below you can find a schematic overview of the UXML implementation for the graph's key.

    #KeyOutline .graph-key-outline
└── #Key .graph-key
    ├── #KeyElement .graph-key-element
    │   ├── #KeyLabel .graph-key-label
    │   └── #StylePreview .graph-key-style-preview
    ...
    └── #KeyElement .graph-key-element
    Note

    #KeyOutline additionally contains a USS class representing the current key placement (e.g. .in-top-center).
